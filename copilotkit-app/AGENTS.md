# 新版本上线后的 UI 验收

- 每次启动或发布新版本后，在实际运行的目标地址刷新页面并完成一次浏览器复查，再交付。构建和类型检查通过之后仍需检查实际渲染和交互。
- 在桌面和手机视口检查改动入口及相邻流程，覆盖加载、空状态、展开与收起、切换页面和返回。验证深浅主题、滚动定位、输入框与主按钮是否可用。
- 注意布局跳动、控件遮挡、横向溢出、突兀滚动和过长动效。尊重系统减少动态效果偏好。
- 发现问题就修复并在最新版本复查。交付时说明实际验收过的路径和未能覆盖的情况。
- 修改交互后用不同数据和操作顺序重复验证。涉及批量或删除时，用临时测试数据覆盖单条、多条、取消、筛选和不可操作状态，并核对操作范围及保留的数据。
